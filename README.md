# DevOps Portfolio

A collection of hands-on projects covering containerization, orchestration, and automation.

## Projects

### [Task API — Dockerized REST API](docker/task-api/)

A multi-container REST API (Node.js/Express, PostgreSQL, Redis) demonstrating production-oriented Docker practices: multi-stage builds, non-root containers, health-checked service dependencies, persistent volumes, and a CI pipeline.

**Stack:** Docker, Docker Compose, PostgreSQL, Redis, Node.js, GitHub Actions
